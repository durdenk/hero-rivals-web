# Odyssey Arena Web Pages

Public website and legal pages for the Odyssey Arena Android game.

- Website: https://durdenk.github.io/hero-rivals-web/
- Privacy policy: https://durdenk.github.io/hero-rivals-web/privacy-policy.html
- Terms of use: https://durdenk.github.io/hero-rivals-web/terms-of-use.html
- Data deletion: https://durdenk.github.io/hero-rivals-web/privacy-policy.html#data-deletion
- Authorized seller declaration: https://durdenk.github.io/hero-rivals-web/app-ads.txt
- Google Play package: `com.cukkacreatives.herorivals`

## Publishing

The files in this directory are designed to be placed at the root of the
[`durdenk/hero-rivals-web`](https://github.com/durdenk/hero-rivals-web)
repository and published from the `main` branch with GitHub Pages.

Use the public privacy-policy URL in Google Play Console. The developer website
must resolve to a host where `app-ads.txt` is available at the root URL checked
by AdMob.
